# 📊 Парсер каталога с мониторингом цен и отчётом в Excel

Скрипт собирает все товары интернет-магазина, переводит цены в рубли по курсу ЦБ РФ, сохраняет их в аккуратную Excel-таблицу и при каждом следующем запуске показывает, **что подорожало, что подешевело, что появилось и что пропало**.

> Демо-проект для портфолио. В качестве примера используется [books.toscrape.com](https://books.toscrape.com/) — учебный магазин, созданный специально для тренировки парсинга. Категории переведены на русский, цены пересчитываются из фунтов в рубли по официальному курсу ЦБ на день запуска; названия книг оставлены как на сайте. Под другой сайт меняются только правила разбора страниц в `scraper.py`.

## Зачем это бизнесу

- следить за ценами конкурентов, не открывая их сайты вручную;
- быстро замечать, когда конкурент снизил цену или у него закончился товар;
- выгрузить чужой или свой каталог в таблицу для анализа;
- запускать по расписанию и получать свежий отчёт каждый день.

**Лист «Сводка»** — главное на одном экране: курс ЦБ, по которому посчитаны цены, сколько товаров, сколько в наличии, сколько подорожало и подешевело с прошлого запуска, плюс таблица по категориям с минимальной, средней и максимальной ценой.

**Лист «Изменения»** — все изменения с прошлого запуска с цветовой подсветкой:

| Цвет | Что значит |
| --- | --- |
| 🟥 | подорожало |
| 🟩 | подешевело или снова в наличии |
| 🟦 | новый товар |
| 🟨 | закончился |
| ⬜ | пропал с сайта |

Для каждого изменения: было, стало, разница в деньгах и в процентах. Сортировка по величине изменения.

**Лист «Товары»** — весь каталог: название (кликабельная ссылка на товар), категория, цена, рейтинг звёздами, наличие и изменение цены. С фильтрами и закреплённой шапкой.

## Возможности

- обход всех категорий и всех страниц пагинации;
- защита от дублей;
- вежливый парсинг: пауза между запросами, повторы при сбоях сети, таймауты;
- автоматический курс ЦБ РФ (с запасным источником) или ручной: `--rate 108.5`;
- цены сравниваются в исходной валюте сайта, поэтому колебания курса не выдаются за «подорожание» всего каталога;
- история цен между запусками (`data/last_run.json`);
- отчёт с датой и временем в имени файла, старые отчёты не перезаписываются;
- демо-режим `--simulate`: показывает, как выглядит отчёт с изменениями, не трогая настоящую историю.

## Технологии

- Python 3.9+
- requests — загрузка страниц
- BeautifulSoup — разбор HTML
- openpyxl — Excel с оформлением, фильтрами, ссылками и форматами чисел
- API ЦБ РФ — курс валют

## Запуск

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

python main.py                  # весь каталог, ~1000 товаров, 2–4 минуты
python main.py --categories 5   # только 5 категорий, для быстрой проверки
python main.py --simulate       # демо отчёта с изменениями цен
python main.py --rate 108.5     # курс вручную, если сайт ЦБ недоступен
```

Отчёты появляются в папке `reports/`.

## Структура

| Файл | Что внутри |
| --- | --- |
| `main.py` | запуск, параметры командной строки, демо-режим |
| `scraper.py` | загрузка страниц и разбор HTML |
| `report.py` | сравнение с прошлым запуском и оформление Excel |
| `currency.py` | курс валют ЦБ РФ |
